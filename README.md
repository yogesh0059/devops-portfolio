* ⚡ Smooth Animations & Typing Effect
* 🧠 Skills & Projects Section
* 🌐 Live Deployment

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **DevOps Tools:** Docker, Git, GitHub
* **Deployment:** Netlify

## 🚀 DevOps Workflow

1. Developed portfolio using HTML, CSS, JS
2. Managed code using Git & GitHub
3. Containerized application using Docker
4. Deployed locally using Docker container
5. Hosted live on Netlify

---

## 🐳 Docker Setup

### Build Image

```bash
docker build -t devops-portfolio .
```

### Run Container

```bash
docker run -d -p 8080:80 devops-portfolio
```
